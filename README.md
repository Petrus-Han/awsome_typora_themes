# Typora Themes Collection

A collection of beautiful, functional themes for Typora, including the classic **Spring** theme with its new Dark Mode and Retro Printer style.

## 🌟 Featured Theme: Spring

The **Spring** theme is designed for clarity, elegance, and a touch of seasonal freshness. It now features a powerful **Dark Mode** and a nostalgic **Printer Style**.

### Features
- **Spring Dark Mode**: A perfectly balanced dark aesthetic that retains the signature green accents.
- **Retro Printer Style**: A unique typography setup using `Courier New` and standard `Songti` to simulate the look of a classic typewriter/printer output.
- **Interactive Animations**: Smooth hover effects on headers, paragraphs, and list markers.
- **Glassmorphism**: Elegant blur effects on blockquotes and metadata blocks.
- **Optimized for Reading**: Carefully tuned line heights and spacings for long-form writing.

## 🛠 Installation

1. Open Typora and go to **Settings** (or **Preferences** on macOS).
2. Navigate to **Appearance** and click the **Open Theme Folder** button.
3. Copy the `.css` files and their corresponding folders from this repository into that folder.
4. Restart Typora or select the new theme from the **Themes** menu.
